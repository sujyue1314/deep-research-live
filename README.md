# 大富翁·名利场 —— AI 驱动的都市资本模拟

《大富翁·名利场》是一个纯文字原生的**类大富翁资本模拟 Demo**，用来展示 Atria-Dawn-Preview 模型在**长程多智能体博弈**中的能力：不是模型画图、不是模型问答，而是模型**扮演三个会记仇、会算计、会谈判的地产大鳄，在 30 个季度里和你真刀真枪地炒楼**。

- 入口：`http://127.0.0.1:5180/`（开发）或 `http://127.0.0.1:3001/`（生产构建）
- 模式：`🎮 开局`（你 vs 3 个 AI，约 30-50 分钟一局）/ `🍿 观战模式`（4 个 AI 对赌 + 毒舌解说员实时点评）
- 同目录的《现场调查局》是独立的深度研究 Demo：`http://127.0.0.1:5180/research.html`（见 [README-research.md](./README-research.md)）

## 它展示了模型的什么能力

1. **人格一致的长程扮演** —— 三个 AI 各有投资哲学与性格：
   - 郑伯昌（老钱·收租公）：只买核心区收租、从不加杠杆、谁缺钱他五折"帮把手"
   - 洪凯文（杠杆炒客）：满杠杆追概念区、拉抬后塞给接盘侠
   - 林曼卿（价值派·做局者）：低谷吸货、泡沫出货，谁领先她就联合谁针对之
2. **记忆与记仇** —— 每个回合模型都会写入 / 读出长期记忆；三回合前你阴过他，这回合他的内心独白和交易提案会原样还回来
3. **自由谈判** —— 不点技能树、不走选项卡：你打字提出任何交易，模型解析意图、核对你公开持仓、报价、还价、翻脸（"你名下连块砖都没有，张口就卖滨江的地？"）
4. **涌现事件** —— 每季度模型生成政策/基建/宏观/黑天鹅新闻并对各区产生量化冲击，行情先于市场反应可见，可以抢跑布局
5. **叙事生成** —— 财经记者体季度战报（往期自动归档）、观战模式解说员实时毒舌、终局为每个玩家撰写人物志特稿

## 架构

```
index.html ── src/                     （React + Vite）
                ├ App.tsx              游戏入口：SSE 事件流 → UI 状态机
                ├ api.ts               REST 行动 + EventSource 订阅
                ├ json-reader.ts       流式 JSON 字段提取器（把 {"thought":"…"} 流实时渲染成可读文本）
                ├ panels.tsx           所有面板组件（市场棋盘/窃听面板/谈判弹窗…）
                └ styles.css           深色"财经终端"主题（红涨绿跌）
server/                                （Node 零依赖后端）
  ├ index.js                           HTTP 服务 + REST + SSE 推送 + 静态伺服
  ├ config.js                          Atria 密钥/端点配置
  ├ engine/
  │   ├ world.js                       世界数据（8 区）+ 确定性市场/财务引擎
  │   └ game.js                        回合状态机、行动校验（含字符串行动容错 + id 模糊匹配）、
  │                                    并发 AI 决策、谈判系统、存档
  └ ai/
      ├ client.js                      /v1/responses 流式客户端（reasoning.effort 有界推理、JSON 断尾修复）
      └ agents.js                      事件引擎 / NPC 决策 / 谈判 / 战报 / 解说员 / 人物志
server/saves/                          每次阶段变更自动存盘，刷新/断线可恢复，历史对局可列表恢复
```

## 关键工程决策（为 demo 效果服务）

- **`/v1/responses` + `reasoning.effort`**：模型是推理型的，`/chat/completions` 上推理链会吃光 `max_tokens` 导致正文为空；`/responses` 可以给思考上界，NPC 决策稳定在 ~7-20s。
- **并发决策、顺序落子**：三个 NPC 同时思考（更接近真实市场的同时出价），引擎按顺序执行解决冲突（同一块地被两人看上，后手失败并记录在市场动态里）。
- **精简提示**：长 prompt 会触发失控推理；关键 prompt 压到 ~1000 字并给出 JSON 行动范例，质量不掉、速度快 5 倍。
- **订阅者守卫**：观战模式在没人看时会挂起，不在后台空烧 token。
- **确定性引擎 + 模型输出强校验**：价格/现金流/破产全是代码算的，模型只能提建议性行动；不合法的行动会被丢弃并如实记录（"试图操作但失败：地块不属于你"），反而增加了真实感。

## 运行

```bash
pnpm install
pnpm dev          # 同时起服务端(3001) + Vite(5180)
# 生产构建：
pnpm build && pnpm start
```

密钥与大富翁共用（`server/config.js`）：`~/.dsh/.credentials.yaml` 中的 `ATRIA_API_KEY`，或环境变量 `ATRIA_KEY`。
端点默认 `https://discovery-api.intern-ai.org.cn/v1`，可用 `ATRIA_BASE_URL` 覆盖。

## 玩法速览

- 每季度 3 个行动点（AP）：买地 / 升级（住宅→商铺→写字楼）/ 卖出 / 抵押 / 还贷
- 空地不收租，升级才有租金；杠杆放大收益也放大月供，利率随宏观与新闻变动
- 现金流断裂会被银行 8 折强平；资不抵债直接破产出局
- 谈判不耗 AP，但对同一个人每季只能谈一轮——你的每一句话都会被记住
- 30 季度后按净资产排名结算，每个玩家获得一篇 AI 撰写的人物志

## 已知限制

- 单季约 60 秒（含新闻生成 + 3 家并发决策 + 战报撰写），追求的是"看他们思考"的过程
- 观战模式完整 30 季约 30-40 分钟；现场演示建议看前几个季度
- 模型偶尔会提交非法行动（地块 id 抄错等），引擎会如实在市场动态里记录失败，这是诚实而非Bug
