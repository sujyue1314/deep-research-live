# 探照灯 · Atria 深度研究 Demo

> 一场可以围观的深度研究直播：不只给你一份结论，而是把得出结论的全过程摊开在桌面上。

打开页面，先入眼的是一份杂志刊首。输入一个真问题后，刊首收拢成一条刊号线——计时、步数、搜索与阅读量实时滚动，左侧思考逐字流出，中栏证据逐张落位，右侧提纲推进、报告逐节成稿。争执也会发生：质疑者会向证据开火，系统守卫会强制造益异源补搜，最后由裁决者按可信度写成报告。

## 特性

- **全过程公开**：思考流 / 搜索 / 开页阅读 / 证据固定 / 报告撰写，每一步都直播可见
- **可核验的准确性**：引文服务端逐字核验、引用编号强校验、URL 溯源、靠主域名交叉验证；每个 `[n]` 都点得回证据卡
- **三方会审**（strict 模式）：调查员取证 → 质疑者挑战 → 调查员答辩 → 裁决者写报告，多智能体辩论全程可视化
- **答记者问**：完稿后继续追问，超纲问题诚实说明「证据不足」，绝不编造
- **分享与回放**：任何时刻一键复制链接，别人打开就是同一条直播或回放（SSE 全量重放，刷新不丢进度）

## 三种模式

| 模式 | 流程 | 适用 |
|---|---|---|
| 快查 | 单智能体 | 快速验证 |
| 深度 | 单智能体，完整深挖 | 完整题目 |
| 严格·三方会审 | 调查员 → 质疑者 → 裁决者 | 展示多智能体辩论与裁决 |

## 快速开始

```bash
pnpm install
pnpm dev          # 服务端 3001 + 前端 5180
```

打开 `http://127.0.0.1:5180/research.html`。

**没有模型密钥也能跑**：服务端自动切换到「演练模式」，回放一条预制调查轨迹（上海近十年常住人口变化与背后原因，含完整三方会审尾段），也可在输入区勾选「演练模式」手动强制。

密钥配置：`~/.dsh/.credentials.yaml` 写入 `ATRIA_API_KEY: sk-xxx`，或环境变量 `ATRIA_KEY` / `ATRIA_API_KEY`（详见 [README-research.md](README-research.md)）。

## 已知限制

- 模型为纯文本输入，本 Demo 输入只有文字；所有视觉效果由 UI 层从结构化事件渲染
- 前端 markdown 子集渲染（列表 / 加粗 / 引用条），不支持表格
- 快查模式步数紧张时可能只写 1 节报告，用「深度」模式获得完整报告
